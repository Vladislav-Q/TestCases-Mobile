## Тест кейсы для мобильного приложения.
Мое написание тест кейсов с результатами, для мобильного приложения.


Задача будет состоять в тестировании мобильного приложения Сбербанк Онлайн и тестирования функционала перевода между своими счетами:										
									
1. Скачать мобильное приложение Сбербанк Онлайн										
2. Провести тестирование функционала перевода между своими счетами:										
-Элементы экрана и бизнес-процесс.										
-Точки входа: Умный поиск, раздел «Платежи», лавашар (ассистент/голосовой помощник)										
-Светлая/темная тема										
-Сворачивание, прерывание процесса (звонок, интернет)
3. Задокументировать тест кейсы по проверкам в стандартном формате (описать сценарий, шаги и результаты)										
4. Протестировать работу диплинка:										
	Android: android-app://ru.sberbankmobile/android-app/ru.sberbankmobile/payments/p2p?type=between_my_account																				

5.Talk back/Voice over
